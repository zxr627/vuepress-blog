# 首页编辑感背景镜片设计

## 目标

在保留现有 VuePress 博客结构、背景图、文章路由、导航含义、深浅色能力和备案信息的前提下，重做首页的视觉层级与背景互动。首页应更像一个有个人气质的中文技术与人文博客，而不是主题默认示例页或特效展示页。

## 设计判断

页面类型：已上线个人博客的保留式改版。

受众：阅读技术笔记、历史随笔和日常文章的中文读者。

视觉语言：克制的中文编辑感，现代但不冷淡，以背景摄影、清晰排版和少量鼠标反馈建立记忆点。

设计参数：

- `DESIGN_VARIANCE: 6`
- `MOTION_INTENSITY: 4`
- `VISUAL_DENSITY: 3`

## 方案

采用“编辑感背景镜片”方案。

首页首屏继续使用现有背景图。标题和副标题采用左对齐的编辑式构图，避免主题默认的居中宣传页观感。鼠标进入首屏后，只在指针附近显示一个尺寸受控的半透明镜片。镜片通过背景位置偏移、轻微放大、饱和度变化、边缘高光和内阴影模拟局部折射，不使用大面积玻璃面板，不遮挡文字，也不改变鼠标指针。

首屏下方保留下一段内容的可见提示。项目入口不再强调外部学习网站，改为博客自身的主要内容入口和近期阅读方向，使首页先介绍本站，再提供外部资源。

## 视觉规则

- 继续使用现有背景图，不新增风格不明的素材。
- 主色沿用现有绿色，但降低饱和度并作为唯一强调色。
- 正文字体继续使用霞鹜文楷，标题与导航使用系统无衬线字体建立层级。
- 首屏只包含站点名、短句、一个浏览入口和必要的背景信息。
- 首页卡片使用统一的小圆角和细边框，不使用大阴影、霓虹、渐变文字和过量悬浮效果。
- 导航保持现有功能，首页视觉层只做背景与文字可读性适配。
- 深色模式保持同一构图，仅调整蒙层、文字和边缘高光。

## 组件边界

### `HomeHeroLens.vue`

负责首屏背景镜片互动。

输入：

- 背景图地址
- 镜片直径
- 最大位移和缩放幅度

输出：

- 指针位置对应的 CSS 自定义属性
- 激活、离开和降级状态

依赖：

- Vue 3 Composition API
- 原生 Pointer Events
- CSS 自定义属性和 `backdrop-filter`

组件只更新元素样式变量，不通过 Vue 响应式状态追踪连续坐标，避免每次鼠标移动触发组件树重渲染。

### 首页样式

放在现有 VuePress 自定义样式目录中，负责：

- 首屏排版与蒙层
- 镜片材质
- 首页内容入口
- 桌面、平板和手机断点
- 深色模式和辅助功能降级

### 首页内容

继续由 `src/README.md` 的首页 Frontmatter 提供基础信息。必要时增加少量首页专用字段或 Vue 组件挂载点，不改变现有文章目录和路由。

## 交互与降级

- 桌面指针设备：镜片跟随鼠标，使用缓动插值，幅度克制。
- 触屏设备：不跟随手指，显示静态背景与固定柔光。
- `prefers-reduced-motion: reduce`：关闭跟随和过渡。
- `prefers-reduced-transparency: reduce`：关闭背景模糊，使用不透明蒙层。
- 不支持 `backdrop-filter`：保留边缘高光和半透明底色，不影响文字阅读。
- 镜片设置 `pointer-events: none`，不拦截导航、按钮和移动端点击。

## 内容结构

首屏：

- 站点名
- 一句中文定位
- 浏览文章入口

首屏之后：

- 最近文章
- 技术笔记
- 历史与随笔
- 关于作者

内容入口优先链接站内已有页面，不新增空页面，不制造虚假数据。

## 性能与可访问性

- 不引入 Three.js、GSAP 或新的动画库。
- 连续指针更新通过 `requestAnimationFrame` 与元素样式变量完成。
- 只动画 `transform`、`opacity` 和背景位置。
- 背景图保留确定尺寸，避免布局跳动。
- 首屏文字在浅色和深色背景区域均有稳定对比度。
- 所有可操作元素保留键盘焦点状态。

## 验收标准

- 桌面端镜片跟随自然，无明显掉帧，不遮挡首屏文字。
- 1366×768 和 1920×1080 下首屏完整，并露出下一段内容。
- 390×844 下无横向滚动，导航和首页入口可点击。
- 深色与浅色模式均可阅读。
- 关闭动效或透明度后，首页仍然完整。
- VuePress 构建通过。
- 现有文章路由、导航、评论配置、备案页脚和微信访问兼容逻辑不受影响。

## 非目标

- 不进行全站主题重写。
- 不修改文章正文样式。
- 不修改 URL、导航文案含义或目录结构。
- 不新增登录、搜索或内容管理功能。
- 不在本次改版中部署到生产服务器。
